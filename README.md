# IT340 Final Project

This uses **MongoDB**, **Express**, **Node.js**, and a **React (Vite) frontend**, deployed and tested on **Linux virtual machines**.

The application displays products from a MongoDB database, allows users to view products, and supports cart and authentication APIs.

---

### Frontend
- React
- TypeScript
- Vite
- React Router DOM
- ShadCN UI
- Tailwind CSS
- Fetch API
- Node.js (for development)
- npm

### Backend
- Node.js
- Express.js
- Mongoose
- MongoDB
- dotenv
- CORS
- JSON Web Tokens (JWT)

### Database
- MongoDB Community Edition
- MongoDB Shell (`mongosh`)
- `mongorestore` for database restore

### Environment / Infrastructure
- Linux (Ubuntu)
- Virtual Machines (VMware / VirtualBox)
- Networking via private IPs
- Ports:
  - MongoDB: `27017`
  - Backend API: `3000`
  - Frontend Dev Server: `8080`
